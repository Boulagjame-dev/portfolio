## 🌌 Overview

**Zakaria.AI** is a high-performance, dark-mode immersive portfolio engineered to showcase production-grade software applications, autonomous AI automations, and operational SaaS tools built by **Zakaria Boulagjame**.

Designed with **Lumina Aesthetics** (Deep Violet `#120b2e`, Neon Mint `#a3ffce`, and Glassmorphism), this application blends cutting-edge web design with engineering precision:
- **Kinetic Typography & 3D Hover Mechanics**: Custom CSS 3D parallax effects with glowing ambient drop-shadows on individual character nodes.
- **Lenis Smooth Inertia**: Fluid 60fps momentum-based scrolling physics for maximum user immersion.
- **Dynamic Category Filtering**: Instant client-side switching between *SaaS & Web Apps*, *Retail & POS*, and *AI & Automation*.
- **Business Outcome Badges**: Clear ROI metrics highlight the exact measurable impact of each project (time saved, revenue captured, overhead eliminated).

### 1. Web Apps & SaaS Engineering
- Modern single-page and server-driven architectures using **React** and **Next.js**.
- High-contrast, responsive interfaces engineered with pure **Tailwind CSS** and bespoke glassmorphic tokens.
- Structured **Schema.org** JSON-LD graphs designed for local search domination and **Generative Engine Optimization (GEO)**.

### 2. Databases & Secure Operations
- Relational schema modeling in **PostgreSQL** with strict **Row-Level Security (RLS)** policies.
- Multi-tenant tenant isolation for B2B platforms ensuring strict institutional compliance.
- Hardware-free retail utilities (live smartphone camera barcode parsing via HTML5 QR scanners).

### 3. Workflow Automation & Orchestration
- Autonomous pipelines designed in **n8n** operating on self-hosted VPS environments.
- Event-driven notifications via **Telegram Bot API** delivering real-time sales and low-stock telemetry.
- Deterministic headless vector rendering rendering 4500×5400px transparent merchandise with zero recurrent image API fees.

### 4. AI & Multi-Agent Intelligence
- Vision pipelines leveraging **Google Gemini Pro Vision** for receipt and business card digitization.
- Modular autonomous multi-agent cognitive frameworks (**MicroHard CAI & MGI**) for continuous growth engineering.

## 💻 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Boulagjame-dev/portfolio.git
   cd portfolio
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
   The compiled bundle will be generated in `dist/`.

5. **Preview the production build locally:**
   ```bash
   npm run preview
   ```
